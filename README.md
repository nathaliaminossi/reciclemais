# 🌱 Sobre o Projeto

O **Recicle+** é uma plataforma desenvolvida com o objetivo de incentivar práticas sustentáveis por meio da reciclagem.

A aplicação busca aumentar a participação da população na coleta seletiva utilizando recursos de **gamificação**, permitindo que os usuários registrem materiais reciclados, acumulem pontos e recebam recompensas, tornando o processo mais atrativo e educativo.

O projeto foi desenvolvido durante o **Projeto Integrador**, unindo tecnologia e sustentabilidade para promover impacto positivo na sociedade.

---


# 🎯 Objetivos

♻️ Incentivar hábitos sustentáveis.

🗑️ Facilitar o descarte correto de resíduos.

📚 Promover a educação ambiental.

🏆 Estimular a reciclagem através de recompensas.

🌎 Conscientizar a população sobre a importância da preservação do meio ambiente.
